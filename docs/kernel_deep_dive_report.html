Kernel Capability

Highly Capable

The NeolyxOS kernel demonstrates extreme maturity for a custom monolithic architecture:

  • Memory: Full Physical (PMM) and Virtual (VMM) memory managers.
  • Interrupts: IDT configured with IST1 for exceptions. PIC remapping complete.
  • Execution: Rings 0 & 3 fully utilized. Transitioning to userspace works perfectly.
  • Booting: Custom NeolyxBootInfo handoff with framebuffers, memory maps, and ACPI tables smoothly handled.
⚡

Syscall Dispatching

Advanced

The syscall mechanism is modern, secure, and performant:

  • Dynamic Macro Generation: Driven by syscall_table.def for a single source of truth.
  • ABI Negotiation: Custom sys_abi_negotiate guarantees compatibility between userspace and kernel.
  • Filtering & Auditing: Uniquely implements per-process filtering (nx_set_syscall_filter) and blocked-call auditing (nx_audit_log).
int64_t nx_syscall_dispatch(num, a1, a2...);
// O(1) jump table lookup with hot-path branch prediction.
📁

Filesystem & VFS

In Progress

The VFS is solid, but native disk FS is lacking:

  • RAMFS: Fully operational. Embeds raw payloads (hello, desktop, nxsh) at boot for immediate execution.
  • Mounts: Capable of resolving nested mounts (e.g. /ramfs/bin).
  • NXFS: Still highly mocked. The kernel depends on a boot marker (boot_info->reserved[0]) rather than a true disk superblock probe to determine "install status".
🧩

Scattered Elements

Architecture Drift

Drivers and UI components are spreading rapidly:

  • NXRender: Currently being split into `Device`, `Layout`, and `Shadow Tree` to achieve zero-dependency UI.
  • Zepra / NXGame Bridge: Massive GPU, Audio, and Input session managers baked directly into the kernel ABI (e.g., sys_nxgame_gpu_acquire).
  • Network: tcpip_init and Socket API exist but NIC drivers are highly segmented.
🔧

Broken / Incomplete

Needs Attention

Critical paths needing engineering focus:

  • Scheduling: sys_yield_impl is currently a no-op because the desktop operates without a strict process context switch environment.
  • Heap Fallback: The kernel uses a hardcoded 64MB global reserve (g_desktop_heap) for the desktop instead of isolated page allocations.
  • Directory Lookups: ramfs_finddir relies on workaround static pointers due to .data segment linking issues.
🛡️

Security & Safety

Production-Grade

Following strict operational manuals:

  • Boot Guard: Deeply embedded watchdog tracking boot success/fail metrics. Triggers recovery on looping panics.
  • SIP (System Integrity Protection): Blocks dynamic module loads and tracks ELF validations.
  • User Pointer Validation: Syscalls explicitly bounds-check and validate user address spaces before copy_to_user.
