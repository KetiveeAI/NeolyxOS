Neo-Aura Desktop Architecture

NeolyxOS Desktop Rendering & Vajra Design Language

1. Core Concepts

NeolyxOS desktop utilizes a custom C-based rendering engine called NXRender to implement the Neo-Aura graphics pipeline, which is styled using the Vajra Design Language.

1.1 Neo-Aura Graphics Pipeline

Neo-Aura represents the physical material properties of the UI. It emphasizes:

  • Glassmorphism: Deep, multi-layered translucency using nx_effect_kawase_blur() for O(1) performance regardless of blur radius.
  • Depth: Soft drop shadows to separate floating windows from the background.
  • Motion: Configurable animation speeds with accessibility overrides.
  • Eye Care: A built-in blue-light filter ("Sattvik Night Mode") applied as the final post-processing pass before flip.

1.2 Vajra Design Language (Theme System)

Vajra is the official color identity of NeolyxOS, rooted in warm, vibrant tones contrasting against deep dark backgrounds. The color definitions live in theme.c and are exposed via theme.h.

Core Palette:

  • Primary: Saffron orange (#E8660A) — used for active focus rings, primary buttons, and the ghost snap preview overlay.
  • Secondary: Deep violet (#6D28D9)
  • Backgrounds: Deep dark navy (#070B14) wallpaper base, Dark surface (#0D1424), Elevated surface (#142038)
  • Text: Off-white (#F0F4FF) primary, Muted blue-gray (#8CA0C0) secondary
  • Accents: Sky blue (#0EA5E9) for badges, Warm amber (#D97706) for gradients.

Note: All inline code comments use these plain English descriptions to remain accessible to international developers, while Vajra Dark remains the official theme name.

2. Rendering Flow

The desktop runs a continuous render loop in desktop_shell.c, targeting a userspace backbuffer which is then flipped to the kernel via nx_fb_flip().

Frame Loop Sequence:

  1. render_background(): Draws the wallpaper image or the Vajra gradient fallback.
  2. yantra_grid_draw(): Overlays a subtle 48px geometric mesh (diamond + crosshair nodes).
  3. render_navigation_bar(): Draws the top system bar.
  4. render_globe_clock_widget(), render_search_bar(), render_desktop_icons()
  5. Tile Preview Overlay: Draws the saffron ghost snap preview if dragging near edge.
  6. render_windows(): Evaluates PiP / Sidebar mode, renders soft drop shadow, renders window content and borders.
  7. dock_render(), app_drawer_render(), control_center_render()
  8. Night Mode Filter: Applies the color temperature adjustment matrix.
  9. nx_cursor_set(): Updates hardware cursor position.
  10. flip_buffer(): Commits the frame to the kernel.

3. Window Management (WM)

3.1 Keyboard Tiling

The WM supports robust tiling via keyboard shortcuts (Super + Arrows for Halves/Maximize/Restore).

3.2 Advanced Tiling Zones

Beyond standard halves and quadrants, the WM supports third-splits for ultrawide monitors (Left Third, Center Third, Right Third, etc).
